# Portfolio

A minimal Next.js portfolio built with the App Router.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Live demo

https://portfolio-seven-steel-6opo75a57d.vercel.app/

## Notes

- Source: `src/app`
- Styles: CSS modules in `src/components`
- Deployment: configured for Vercel
